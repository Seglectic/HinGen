# HinGen

A browser-based generator for parametric, print-in-place butt hinges. Set the leaf size, thickness, knuckles, clearance and screw holes, then download an STL.

Everything runs locally in your browser: [OpenSCAD](https://openscad.org) is compiled to WebAssembly and renders in a Web Worker, and nothing is uploaded. It's a static site, so it works on GitHub Pages, any static file server, or offline.

## Using it

- **Leaf width** is measured from the pin centre to the outer edge of one leaf, so overall width = 2 × leaf width.
- With the open angle at 0°, the leaf bottoms are flush with the knuckle, so the hinge lies flat on the bed. The knuckle stands one leaf thickness above the leaves.
- The settings live in the URL hash. **Copy link** shares an exact configuration.
- If a print-in-place hinge comes out fused, raise **Clearance**. A good starting point is 0.4 mm.

## Running locally

ES-module workers and `fetch` don't work over `file://`, so serve the folder:

```sh
python3 -m http.server 8765
# open http://localhost:8765
```

## Layout

| Path | What |
| --- | --- |
| `index.html`, `style.css`, `app.js` | UI, three.js viewer, URL-hash state |
| `params.js` | Parameter schema: labels, ranges, mapping to the SCAD variables |
| `worker.js` | Runs OpenSCAD WASM (`--backend=Manifold --export-format=binstl`) |
| `models/butt_hinge.scad` | The hinge model (unmodified v3.8) |
| `vendor/` | Third-party runtime files, generated by `tools/vendor.py` |

To add a parameter, add an entry to `params.js` with the SCAD variable name. The worker passes everything through as `-D name=value`.

### Updating vendored files

```sh
curl -sL https://registry.npmjs.org/openscad-wasm-prebuilt/-/openscad-wasm-prebuilt-1.2.0.tgz | tar xz -C /tmp/osw
curl -sL https://registry.npmjs.org/three/-/three-0.170.0.tgz | tar xz -C /tmp/three
python3 tools/vendor.py /tmp/osw/package /tmp/three/package
```

The OpenSCAD package inlines its `.wasm` as base64. `vendor.py` splits it into a real `openscad.wasm` so the browser compiles it once and reuses it for every render.
